Place your static assets here. They will be served at the root path.

Required for the React portfolio:
1. Copy Malik-Umair.png to this folder (or leave in project root and reference from there).
2. Copy the projectPictures folder here so project images load at /projectPictures/...
3. Copy umair.jpg here for the favicon.

If you run from project root with Vite, you can also keep Malik-Umair.png and projectPictures in the project root and configure vite to use them (e.g. publicDir or import from src/assets).
